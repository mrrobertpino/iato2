Vocabulary

Network
A group of connected devices.
Route
A path from one point to another.
Node
A point in a graph or network.
Connection / edge
A link between two nodes.
Cost
A number representing how expensive a connection or path is.
Shortest path
The path with the lowest total cost.
Weighted graph
A graph where connections have values or costs.
Dijkstra’s algorithm
A method for finding a lowest-cost path through a weighted graph.
Router
A device that helps move data between networks and choose where it goes next.
